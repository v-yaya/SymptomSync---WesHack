### Health & Wellness Tracker 🫀
A health tracking application engineered to help users seamlessly monitor chronic conditions, infectious diseases, and mental health metrics. The platform provides intuitive daily symptom check-ins, automated medication/daily maintenance reminders, personalized health insights, and interactive monthly data visualizations.

### Key Features 🔑
* Daily Symptom Check-Ins: Track physical and mental health metrics daily to keep an accurate record of your well-being.
* Interactive Data Visualizations: Map trends over time using graphical displays to better understand health patterns.
* Automated Daily Maintenance & Reminders: Stay on top of medications, daily tasks, and health routines.
* Condition & Disease Tracking: Dedicated tracking models tailored for both chronic illnesses and infectious diseases.
* User Management: Personalized user profiles to securely store log history and individual preferences.

### Tech Stack & Architecture 💻
Language: Python
GUI / Graphics Layer: graphics.py, button.py
Data & Logic Layer: Object-Oriented Design (userclass.py, symptomlogclass.py, disease.py, DailyMaintenance.py)
Visualization Engine: visual.py
